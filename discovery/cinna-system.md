# How Cinna Davis’s agents move a conjecture into the catalogue

Read on 25 November 2026 from the cloned publication and research branches. Cinna Davis and GPT-6.2 Astra receive collection-level credit. The project also credits outside contributors on individual results. For the Brown–Mol case, the tracking issue identifies the agent roles and their assignments. The public evidence supports reconstruction of the handoffs. The agents’ private prompts, total compute, and exact runtime configuration remain unknown. | Handoff | What the next agent receives |
|---|---|
| Find a problem | An exact conjecture in a primary paper, its hypotheses, and a reason the answer would matter. Screening notes compare paper revisions, problem databases, and known counterexamples. [Research log](https://github.com/1337isnot1337/solved-conjectures/blob/31df82431bf2d04979544b6f5c249e2e0958c788/research/2026-11-21-combinatorics-screening.md) |
| Reserve the target | A tracking issue names the original statement, distinguishes nearby results, and assigns work. The policy calls for searching alternative names, formal libraries, competing proofs, and both repository branches. [Issue 210](https://github.com/1337isnot1337/solved-conjectures/issues/210) · [Eligibility rules](https://github.com/1337isnot1337/solved-conjectures/blob/31df82431bf2d04979544b6f5c249e2e0958c788/AGENTS.md) |
| Construct a proof or witness | The solver delivers the precise conclusion, construction, and reasoning. For a universal inequality, one certified violation can settle the original question. [Brown–Mol proof](https://github.com/1337isnot1337/solved-conjectures/blob/a51917c3fccb97c4a5c34537d5e2e4ad612f109e/results/brown-mol/PROOF.md) |
| Challenge correctness and priority | The analysis reviewer rederives the mathematics. A separate reviewer matches the claimed theorem against earlier results. In this case a coordinating reviewer also checked the proof against its source. A valid derivation can still fail the novelty check. [Mathematical review](https://github.com/1337isnot1337/solved-conjectures/blob/a51917c3fccb97c4a5c34537d5e2e4ad612f109e/results/brown-mol/ANALYSIS_REVIEW.md) · [Priority audit](https://github.com/1337isnot1337/solved-conjectures/blob/a51917c3fccb97c4a5c34537d5e2e4ad612f109e/results/brown-mol/ALGEBRA_PRIOR_AUDIT.md) · [Coordinating review](https://github.com/1337isnot1337/solved-conjectures/blob/a51917c3fccb97c4a5c34537d5e2e4ad612f109e/results/brown-mol/ROOT_REVIEW.md) |
| Verify and publish | Record the scope of written proofs, exact computations, and Lean checks. A reviewed written result can be published before full formalization. A focused change on the publication branch links the theorem, reviews and verification, then the coordinator reconciles the issue and checks the live catalogue. **An accepted witness.** A combinatorics agent built a 1,001-vertex tree. Its subtree polynomial has a root in a disk Brown and Mol’s conjecture forbids. In the clone we ran the Python checker with Python 3.14.3 and matched the stored JSON, including the exact radius of 1/1,000 and one root in that disk. This replay checks the finite witness. The article separately proves an infinite family, and the repository records a standalone Lean replay and a pending combined gate at the inspected revision. [Result and verification scope](https://github.com/1337isnot1337/solved-conjectures/blob/a51917c3fccb97c4a5c34537d5e2e4ad612f109e/results/brown-mol/README.md) · [Recorded output](https://github.com/1337isnot1337/solved-conjectures/blob/a51917c3fccb97c4a5c34537d5e2e4ad612f109e/results/brown-mol/check-output.json)

**A rejected discovery claim.** The campaign derived a generating function for two conjectures of Kellner. A second agent searched GitHub using the author’s surname and followed a reference to Matsuno’s earlier resolution. Searching only the original paper identifier had missed it. The project retained the derivation on its research branch and excluded it from discovery credit.
