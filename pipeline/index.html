Can we prepare a quantum code with one fewer gate?

  1. Start with a published question. The Golay code protects quantum information. Researchers can prepare its logical zero state with 44 gates that connect pairs of qubits.
  2. Set the target. Find a circuit that reaches exactly the same 23-qubit state with 43 such gates or fewer. Extra qubits and measurements are excluded.
  3. Try a circuit. Remove a gate from the published design. Change the other gates, which qubits they connect, or their order.
  4. Run it backwards. Start with the desired state and undo the proposed gates. If every qubit ends up on its own, free single-qubit gates can prepare the starting state.
  5. Check the winner. Rebuild a candidate as a forward circuit and verify the complete output state. Until then, a trial is just a trial.
