Start with a row of arrows

  1. Pick a question. Each arrow points up or down. Can we arrange 13 arrows to get the lowest energy?
  2. Give each row a score. Slide a copy along the row. Count matches minus mismatches, square that number, and add it up over all slides. Lower is better.
  3. Try every choice. There are 8,192 rows. A program can score all of them, so the smallest score settles this exact question.
  4. Check it another way. A second calculation scores the same rows by counting disagreeing bits. Both give 6. Four rows reach it.
  5. Say what we learned. The 13-arrow answer was already known. For longer rows we can ask a smaller question and say exactly which changes we checked.
