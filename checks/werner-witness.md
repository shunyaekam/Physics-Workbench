# Replaying a Werner endpoint witness

The registered Vienna Problem 2 asks whether there exists an NPT state from which entanglement cannot be distilled for any finite number of copies. The four- and five-copy search uses the specific qutrit state $\rho=(I-F/2)/(15/2)$, where $F$ exchanges Alice and Bob. A negative rank-at-most-two expectation certifies distillability for this particular state and copy count. The broader existential question remains open for either outcome of this test. [Original problem and distillation criterion](https://oqp.iqoqi.oeaw.ac.at/undistillability-implies-ppt) · [Partial-trace formulation](https://arxiv.org/abs/2310.05726v5)

Run `python3 -m checks.werner_witness witness.json` from the repository root. The JSON object contains `copies` (4 or 5) and `terms` (one or two pairs of sparse local vectors). Each local entry is a triple of integers giving the basis index, real coefficient and imaginary coefficient. Each index encodes a length-$k$ base-three word with the least significant digit first. Each term contributes $a\otimes b$, and their sum $v$ has Schmidt rank at most the number of terms. The checker rejects the zero vector.

Partial transposition takes $F$ to $|\Omega\rangle\langle\Omega|$ for the unnormalized $|\Omega\rangle=\sum_{j=0}^2 |jj\rangle$. The pair-element contraction evaluates the quadratic form of $(I-|\Omega\rangle\langle\Omega|/2)^{\otimes k}$ on $v/\|v\|$. An independent implementation expands the same tensor power over all subsets of the copy indices and takes squared norms of the partially traced coefficient matrix. The two fractions must agree. Dividing their common value by $(15/2)^k$ gives the expectation for the normalized density matrix.

With no filename, the command replays $(|00\rangle+|11\rangle)\otimes|00\rangle^{\otimes 3}$, ordered across the Alice–Bob cut. Its normalized score is exactly zero at the endpoint. Replacing $1/2$ by $2/3$ in the underlying contractions gives $-1/81$ for this control. The fixed-parameter checker rejects this substitution. For a nonnegative score, the result says only that the submitted vector failed to certify distillability.
