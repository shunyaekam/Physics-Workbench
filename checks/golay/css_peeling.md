# Golay construction by extracting one qubit at a time

Start with the binary supports of every pure-X and pure-Z stabilizer of the cyclic logical zero. A stabilizer of weight \(s\) can be reduced to a single-site operator with \(s-1\) CNOTs. Choose a root in its support and a tree on the support. For an X word, a CNOT from parent to child clears the child's X when both still carry X. For a Z word, reverse control and target. Remove the leaves first. At the end the state factors as a one-qubit Pauli eigenstate times a smaller CSS state. The chosen circuit uses H and CNOT gates with positive CSS generators, so the product axes determine the forward preparation. The independent signed checker verifies that conclusion for every recorded circuit.

The star version has a useful resource bound. An X step shortens the X code at its root, retaining the representatives that vanish there, and punctures the Z code. A Z step does the reverse. Consequently each X step costs at least \(7-z\) gates after \(z\) preceding Z steps, with zero as a floor. The initial X distance is eight and only Z punctures can decrease it. Likewise a Z step costs at least \(6-x\), since the initial Z distance is seven. The distances can be verified by enumerating the two binary spaces generated by the fixed polynomial. Exactly eleven X roots and twelve Z roots must be used because each step lowers the dimension of its chosen space by one. Pair the first six X steps with the first seven Z steps. In each pair the earlier step pays for the later one under the respective bound. This gives **at least 42 gates** for every pure-star construction in this family. A mixed strategy using general trees can change the remaining supports differently. The bound does not exclude the 43-gate target, either inside this restricted search or for general Clifford circuits.

Both pilots use the same 128 seeds and six candidate choices per extraction. The constructor starts from the cyclic stabilizers alone and independently checks every finished circuit in both directions. Each JSON file records the distribution of gate counts and a replayable signed witness for its best seed.

```sh
python3 checks/golay/css_peeling.py > /tmp/css-stars.json
cmp /tmp/css-stars.json campaign/golay-focus/css-stars.json
python3 checks/golay/css_peeling.py --tree > /tmp/css-trees.json
cmp /tmp/css-trees.json campaign/golay-focus/css-trees.json
```

The [first branching follow-up](../../campaign/golay-focus/css-branch.json) starts from the first 47-gate witness. It visits all 21 single-parent substitutions consistent with the original leaf-removal order in either of its first two extractions. Eight independently seeded tail constructions per branch produced 168 signed target circuits. The best used 47 CNOTs, including 22 circuits at that cost. Reproduce with `python3 checks/golay/css_branch.py`.
