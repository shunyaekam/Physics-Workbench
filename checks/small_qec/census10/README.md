# Ten qubits encoding two at distance four

Every binary stabilizer code with these parameters needs maximum generator weight at least six. The supplied Grassl code attains six. The lower bound uses the completeness of the Danielsen–Parker classification of connected graph states under local Clifford operations and qubit permutations. [Classification](https://doi.org/10.1016/j.jcta.2005.12.004) · [Graph representatives](https://www.codetables.de/larsed/vncorbits/) · [Zhang’s parent-space method](https://yuxuanzhang1995.github.io/agentic-research/lowweight-two-logical-distance-four/) · [Grassl witness as Pauli strings](https://qecchallenge.com/codes/10-2-4.html)

From the repository root run `python3 ops/witness.py wei-10-2-4 checks/small_qec/ten-two.json`. The command checks the ten catalogue-file SHA-256 digests before reading the graphs. For offline replay set `OO_GRAPH_CATALOG` to a directory containing the matching ten graph6 files. A second implementation uses C++17. In a temporary copy of this folder run `python3 graphs.py`, compare the generated all10.txt SHA-256 with `b1a7d75bd683b1f2f54f245d312e6df593a6c6355dd6b9903ac5e508a49e0763`, then run `c++ -O2 -std=c++17 classify.cpp -o classify && ./classify < all10.txt`.

Every rank-eight stabilizer extends to a maximal commuting Pauli group. Transform this parent by a local Clifford and site permutation into graph form. An element with binary mask x has Z mask Γx. Its rank-eight subgroups are exactly the annihilators of two-dimensional binary label spaces K. For a physical Pauli (x,z), the parent syndrome is z+Γx. To enforce distance at least four, each error of weight one through three with nonzero syndrome must have syndrome outside K. Each such error of zero syndrome belongs to the parent and its label x must annihilate every member of K. This last test includes degenerate codes.

The census builds all unordered direct sums of connected components with total size ten, including isolated qubits. Among 3,990 parent representatives, exactly ten have admissible planes. All 47 qualifying parent-plane pairs have rank zero for stabilizers of weights one through five. These 47 count embedded subspaces, and can give equivalent codes. The C++ census also recovers the same weight enumerator for each of the 47 subspaces. The proof uses the published orbit classification as input. Our two implementations independently enumerate the subspaces conditional on that classification.
