# Independent audit, 26 November 2026

A separate reviewer implemented the census in Python directly from the ten connected graph6 representative lists. The primary search uses C++ and a separate graph6 decoder. The Python program assembles disconnected parents by multisets of components, indexes the full stabilizer parent using X masks and computes the span of its light elements for each valid two-dimensional syndrome plane. Both implementations test the condition on parent elements of weights one to three as well as low-weight errors outside the parent. This includes degenerate possibilities.

Both obtained 3,990 parents, 10 parents with admissible planes, 47 parent-plane pairs, and rank zero for the light-stabilizer subspace in every pair. These are embedding counts. The two programs share the external classification; their agreement checks the subsequent reduction and enumeration. The direct upper witness in ten-two.json has 90 weight-four logicals and none at weight one, two or three. The existing weight-six construction and the exhaustive exclusion together settle the optimum.

A search for the explicit check-weight optimum in Wei et al., Zhang’s paper and source package, the QEC Challenge data, GitHub and literature searches found no previous explicit resolution of this particular interval. Wei gave 5–6, Zhang’s ten-qubit result excluded weight four, and Grassl supplied the attaining code. The historical novelty claim is limited to the sources examined.
